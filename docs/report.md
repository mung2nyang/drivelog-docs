## 로드맵 71 로그인 차주의 기사 초대는 차량·시작일이 있어야 저장 `[x]`

코드 리뷰(2026-10-14)로 로드맵 71번 등재 `[확인: 2026-10-14 보리]`, 순서 ①(데이터 저장·유실). 70번 다음. 플레이북 트리거 해당(저장 경로) — `docs/testing-playbook.md` 열람함. DB 변경 없음.
AGENTS §8-6: 원본 앱 대조 결과 **이관 누락**으로 분류합니다. 원본은 차량·시작일이 없으면 저장하지 않았습니다(`ubiquitous-parakeet/driver-link.js:392-397` "기사 이름, 할당 차량, 시작일을 입력해 주세요.").
보리 결정(2026-10-14): 비회원 규칙은 그대로 둡니다. 안내는 팝업이 아니라 화면 안 안내 한 줄로 하고(Hallmark·ui-ux-pro-max 검토 뒤), 회원 초대 창에는 "(필수)"를 표시합니다.

### 쉬운 요약
- **무엇을:**
  - 로그인 차주가 기사 초대를 만들 때, 배정 차량과 시작일이 없으면 저장하지 않고 "기사 이름, 배정 차량, 시작일을 입력해 주세요." 안내를 띄웁니다. 초대 창의 두 칸 이름에는 "(필수)"를 붙입니다.
  - 차량번호가 등록된 기사 차량이 아니면 "등록된 기사 차량 번호를 입력해 주세요."라고 알려 줍니다.
  - 비회원이 기사 연동 관리에 들어오면 왜 초대를 못 하는지 안내 한 줄을 보여 줍니다.
- **왜:**
  - 지금은 차량을 비워도 "초대를 저장했습니다"가 뜨지만 서버엔 저장되지 않습니다. 그래서 기사가 코드를 넣으면 "코드가 맞지 않거나…"가 뜨고, 차주가 앱을 다시 켜면 초대가 사라집니다.
  - 없는 차량번호를 치면 "네트워크 상태를 확인해 주세요"라는 엉뚱한 안내가 나옵니다.
  - 비회원은 초대 버튼이 없는데, 그 이유를 알려 주는 안내가 없습니다.
- **달라지는 것:** 저장된 것처럼 보이는데 실제로는 없는 초대가 더 이상 생기지 않고, 무엇이 필요한지 저장 전에 보입니다.

### 현재 상태 (코드 확인)
- `lib/requestDriverInviteSave.js:44-50` — 차량이나 시작일이 없으면 서버를 건너뛰고 `commitLocalOnly`로 메모리에만 둡니다. 로그인 계정의 기사 목록은 기기에 저장되지 않습니다(`directMutationActions.test.js:732` "로그인 불완전 초대도 LS 미러를 쓰지 않는다").
- `lib/requestDriverInviteSave.js:57-61` — 차량번호가 목록에 없거나 서버 번호가 없으면 `SAVE_FAIL_TOAST`("저장에 실패했습니다. 네트워크 상태를 확인해 주세요.")를 띄웁니다.
- 입력 검사 `domain/drivers.js:77-83` `upsertDriver` — 차량을 적었을 때만 시작일을 요구하고, 차량은 비워도 통과합니다. 비회원·로그인이 같이 쓰는 함수입니다(호출 14곳).
- 이 경로를 타는 곳은 기사 연동 화면 `components/DriverConnectionPage.jsx:69`입니다. 차량 등록과 함께 만드는 초대(`lib/carInviteFromDraft.js:47-49`)는 항상 차량·시작일이 있어 영향이 없습니다.
- **비회원은 초대를 새로 만들 수 없습니다.**
  - "+ 초대" 버튼이 로그인 회원에게만 보입니다(`DriverConnectionPage.jsx:168` `{cloud && …}`).
  - 차량 등록 창의 기사 연동 칸도 회원만 보입니다(`cars/CarFormModal.jsx:48` `showConnect = isSub && cloud`).
  - 비회원 화면에는 "초대된 기사가 없습니다."만 보입니다(`DriverConnectionPage.jsx:120`).
- 초대 창(`DriverFormModal.jsx:73·83`) 칸 이름은 "배정 차량"·"계약 시작일"이고, 무엇이 꼭 필요한지 표시가 없습니다.

### 목표 상태 (기대 동작)
1. 로그인 차주가 배정 차량이나 시작일 없이 초대를 저장하면 "기사 이름, 배정 차량, 시작일을 입력해 주세요." 안내가 뜹니다. 창은 열린 채 그대로고, 서버·화면 목록은 바뀌지 않습니다.
2. 로그인 차주가 등록된 기사 차량이 아닌 번호를 넣으면 "등록된 기사 차량 번호를 입력해 주세요." 안내가 뜹니다. 창은 그대로입니다.
3. 차량은 있는데 아직 서버 번호가 없으면(차량 저장 직후 등) "선택한 차량이 아직 저장되지 않았습니다. 잠시 후 다시 시도해 주세요."가 뜹니다(원본 문구에서 "클라우드"만 뺌).
4. 차량·시작일이 맞으면 지금처럼 서버에 저장됩니다(변화 없음).
5. 로그인 회원의 초대 창에서 칸 이름이 "배정 차량 (필수)"·"계약 시작일 (필수)"로 보입니다. 비회원이 옛 초대를 고칠 때는 지금처럼 "(필수)"가 없습니다(비회원 규칙은 그대로이기 때문).
6. 비회원이 기사 연동 관리에 들어오면, 기사 연결 현황 아래에 안내 한 줄이 보입니다: "기사 초대는 로그인 후 쓸 수 있습니다. 로그인하면 배정 차량과 시작일을 넣어 초대할 수 있습니다." 로그인 회원에게는 보이지 않습니다.
7. **비회원 저장 규칙은 그대로입니다**(옛 초대를 고칠 때 차량 없이도 저장 가능).
