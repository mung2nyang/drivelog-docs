### 쉬운 요약
- **무엇을:** 미수금 화면에서 거래처 한 달치를 한 번에 입금 완료로 바꾸는 두 버튼(목록의 "입금완료", 상세의 "전체 입금 완료 처리")을 누르면, 바로 처리하지 않고 "몇 건·얼마를 입금 완료로 처리할까요?" 확인 창을 먼저 띄운다.
- **왜:** 지금은 한 번 누르면 바로 한 달치가 다 입금 완료가 되고, 되돌리기는 한 건씩만 된다. 잘못 누르면 되돌리기가 힘들다. (입금 취소는 이미 확인 창이 있다.)
- **달라지는 점:** 확인 창에서 [입금 완료]를 눌러야 처리된다. [취소]면 아무것도 안 바뀐다.

### 목표 상태 (기대 동작)
1. "입금완료"(목록)·"전체 입금 완료 처리"(상세)를 누르면 확인 창:
   - 제목: `{거래처} {M}월분 미수 {N}건, {금액}원을 모두 입금 완료로 처리할까요? 되돌리기는 한 건씩만 할 수 있어요.`
   - 버튼: [취소] / [입금 완료](빨간 버튼 아님 — 돈이 나가는 게 아니라 기록만 바뀜).
2. [입금 완료] → 지금처럼 처리·저장·안내 문구, 상세 화면이면 목록으로 돌아감(지금과 같음).
3. [취소]·Esc → 아무것도 안 바뀌고 화면 그대로(저장 0회).
4. 건수·금액은 그 순간의 미수 목록 기준(받을 돈이 남은 건만).
5. 저장 중(`saving`)에는 지금처럼 다시 누를 수 없다.
