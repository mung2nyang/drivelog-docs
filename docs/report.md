### 쉬운 요약
- **무엇을:** 설정 스위치를 빠르게 연달아 눌러도 앞에서 바꾼 것이 되돌아가지 않게 합니다. 설정 저장을 한 번에 하나씩 차례로 하고, 각 저장은 **바로 앞 저장이 끝난 최신 설정** 위에 바꿀 값을 얹습니다.
- **왜:** 지금은 저장할 때 "누른 순간의 설정"에 바꿀 값을 얹은 뒤 서버 저장을 기다립니다. 앞 저장이 끝나기 전에 다른 스위치를 누르면, 두 번째 저장이 앞 변경이 빠진 옛 설정으로 서버와 화면을 덮습니다.
- **달라지는 것:** 앱 설정·알림 종류 끄기·고정 장소 핀처럼 빠르게 여러 번 눌러도 누른 것이 다 남습니다. 화면 모양은 그대로입니다.

### 목표 상태 (기대 동작)
1. 같은 계정의 설정 저장은 한 번에 하나씩, 누른 순서대로 합니다. 앞 저장이 끝나야(성공이든 실패든) 다음을 시작합니다.
2. 각 저장은 시작할 때의 최신 설정(앞 저장이 성공했으면 그 결과) 위에 바꿀 값을 얹습니다.
3. 목록·묶음 설정(`subCarSettings`·`notifOff`·`pinnedLocations`)은 "바꾸는 방법"(최신 설정을 받아 바꿀 값을 돌려주는 함수)으로 넘겨서, 저장 차례가 왔을 때 최신 목록에서 계산합니다.
4. 앞 저장이 실패하면 지금처럼 안내가 뜨고 그 변경만 빠집니다. 뒤 저장은 이어서 합니다.
5. 로그인 저장은 지금처럼 서버 성공 뒤에만 화면에 반영합니다(sot `:539`). 비회원은 지금처럼 기기에 바로 저장합니다(차례만 지킴).
6. 바깥에서 보이는 결과(반환값·안내 문구)는 지금과 같습니다.
