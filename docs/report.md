### 목표 상태 (기대 동작)
1. 입력 칸(콜 상세 새로·수정, 정비/주유/기타 새로·수정·종류 고르기)이 열리면 같은 주소로 붙잡기 기록을 1장 쌓는다(상태에 표시, 달력에서 들어온 표시 `from`은 그대로 유지).
2. 입력 칸이 열린 채 휴대폰 뒤로가기 → 화면은 일지 그대로, 36번과 같은 확인 창. [계속 입력] → 입력 그대로, 붙잡기 기록 다시 쌓음. [나가기] → 입력 칸 닫고 위 ← 와 같은 곳(달력·홈, 직접 연 일지면 그 달 달력)으로.
3. 입력 칸을 [저장]·[취소]·같은 단추 다시 누르기로 닫으면 붙잡기 기록을 조용히 뺀다(확인 창 없음) — 닫은 뒤 뒤로가기 1번에 바로 이전 화면.
4. 입력 칸이 열린 채 위 ← → 지금처럼 확인 창 1번, [나가기]면 붙잡기 기록까지 빼고 나감(일지에 한 번 더 머무르지 않음).
5. 입력 칸이 열린 채 아래 메뉴·사이드 메뉴로 이동 → 지금처럼 묻지 않고 이동하되, 붙잡기 기록을 먼저 빼서 빈 일지 기록이 남지 않음(그 화면에서 뒤로가기했을 때 일지로 돌아오지 않음 — 63번 기록 수 그대로).
6. 입력 칸이 닫혀 있으면 모든 이동이 지금과 같다. 설치 앱 홈 종료 안내(17·63번)도 그대로.
