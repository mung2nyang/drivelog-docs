### 쉬운 요약
- 마이크로 물으면 답(되묻는 말 포함)을 xAI 목소리로 읽어 주는데, 이것도 부를 때마다 요금이 나간다. 말 읽기처럼 계정마다 하루 20번까지만 읽는다.
- 20번을 넘으면 **소리 없이** 화면 아래 알림으로 안내 문구만 띄운다. 휴대폰 기본 목소리로 대신 읽지도 않는다. 답 글자는 지금처럼 카드에 보인다.
- 다음 날(한국 시각 0시) 다시 읽어 준다.

### 목표 상태 (기대 동작)
1. 서버 `unbiseo-voice`: 로그인·문장 검사를 통과한 뒤 xAI를 부르기 **전에** `use_unbiseo('voice', 20)`으로 1회 셈(A와 같은 방식). 넘으면 xAI를 안 부르고 429 `{ error: 안내 문구, limit: 20 }`. 셀 수 없으면 xAI를 안 부르고 503 "잠시 뒤 다시 시도해 주세요."(앱은 지금처럼 휴대폰 목소리). xAI가 실패해도 1회, 로그인 실패·문장 틀림은 안 셈. 기록에 문장을 남기지 않음, 세기 실패만 `count_failed`.
2. 안내 문구: 말 읽기와 **같은** "오늘 운비서를 20번 모두 썼어요. 내일 다시 써 주세요."(숫자는 서버 답의 `limit`, 못 읽으면 숫자 없이 — 말 읽기와 같은 방식) `[확인: 2026-11-04 보리 — "오늘 운비서를 20번 모두 썼어요. 내일 다시 써 주세요. 이거면됫지 더 하지마"]`.
3. 앱 `unbiseoVoice.ts`: 429면 null 대신 "다 씀"과 위 문구를 돌려줌. 다른 오류는 지금처럼 null.
4. 앱 `useSpeechOutput.ts`: "다 씀"이면 휴대폰 목소리로 읽지 않고, 읽는 중 표시를 끄고, 넘겨받은 알림 함수로 문구를 한 번 띄움.
5. 앱 `useUnbiseoAssistant.ts`: `useSpeechOutput`에 `showToast`를 넘김(한 줄). 답 문장·되묻는 말 둘 다 같은 길.
