### 현재 상태 (코드 확인)
- `unbiseo-parse`는 날씨 말을 unknown으로 돌린다. 지시문에 "날씨·뉴스·잡담은 unknown. 예: 오늘 날씨 어때 → unknown"이 있다(`grok.ts`).
- 날짜 표(`dateTable`)에는 오늘·어제·그제·3~6일 전만 있다. 내일·모레 줄은 없다(운행 기록은 앞날이면 오늘로 바꿈 — `index.ts` `dayOf`).
- 앱은 위치를 쓴 적이 없다(`geolocation` 0건).
- 서버 함수는 `unbiseo-parse`(index 189줄)와 `unbiseo-voice`(96줄) 두 개다. 둘 다 Verify JWT를 끄고, 로그인은 함수 코드(`auth.getUser`)에서 확인한다.

### 목표 상태 (기대 동작)
1. `unbiseo-parse`에 새 종류 `kind: 'weather'`, 칸 `weather: { date, place }`를 넣는다.
   - `date`: 날짜 표에 **내일·모레 줄을 더해** AI가 고른다. 날씨일 때만 앞날을 쓰고, 운행·지출의 "앞날이면 오늘"은 그대로 둔다. 말이 없으면 오늘.
   - `place`: 들은 지역 이름 그대로(예: "평택", "부산 강서구"). 말 안 했으면 `''`(앱이 현재 위치로).
   - 지시문의 "오늘 날씨 어때 → unknown" 예는 weather로 바꾸고, 뉴스·잡담은 그대로 unknown.
2. 새 함수 `unbiseo-weather`(로그인 계정만, `unbiseo-voice`처럼 함수 코드에서 확인).
   - 받는 것: `date`(YYYY-MM-DD)와 둘 중 하나 — `place`(지역 이름) 또는 `nx`·`ny`(기상청 격자 번호).
   - `place`면 함수 안의 **지역 → 격자 표**(기상청 격자 엑셀의 시·군·구 이름)에서 찾는다. 못 찾으면 "그 지역은 찾지 못했어요" 신호를 준다.
   - 기상청 단기예보에서 그 날의 하늘 상태(맑음·구름많음·흐림), 비·눈 여부, 최저·최고 기온, 가장 높은 강수 확률을 뽑아 돌려준다.
   - 오늘·내일·모레 밖이면 "범위 밖" 신호를 준다.
   - 키는 비밀값 `KMA_API_KEY`(보리만 다룸)다. 기상청이 느리거나 실패하면 "잠시 뒤 다시"를 준다(재시도 없음).
   - 격자 번호, 지역, 날씨 내용은 함수 기록에 남기지 않는다(끝난 이유·걸린 시간만).
3. 운행·지출·질문·고정·거래처·문자·잡담 종류는 지금과 같다(기존 시험 문장 전부).
