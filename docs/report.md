### 현재 상태 (코드 확인)
- 아래 메뉴: `app/AppShell.jsx:117-128` `selectTab`이 늘 새 기록을 쌓음(`navigate(...)`, 교체 아님). 홈 → 달력 → 매출 → 마이페이지 → 홈이면 기록 5장.
- 화면 위 ← : `app/AppShellRoutes.jsx:49` `backTarget`('/app' 또는 '/app/me')으로 **새 기록을 쌓으며** 이동 — 이 방식이 10곳(`navigate(backTarget)` 검색 10건: 차량·거래처 2·개인정보·설정·지출·서류·공지·문자 설정 등), `navigate('/app')` 2곳(개인정보 연동 해제 뒤 `:88`, 고객센터 `:98`). 그래서 ← 로 돌아가도 휴대폰 뒤로가기는 방금 그 화면으로 다시 들어감.
- 이미 한 장 돌아가는 곳(`navigate(-1)`): 연동 기사 화면들(`:69-73`, `:94-95`), 알림(`:101`), 하루 화면 닫기(`MainPageRoute.jsx:60`, `workLogNavigation.js`) — 그대로 둡니다.

### 목표 상태 (기대 동작)
1. 홈에서 시작해 아래 메뉴만 여러 번 오가도, 어느 메뉴에서든 휴대폰 뒤로가기 1번에 홈, 1번 더에 종료 안내.
2. 화면 위 ← 로 돌아온 뒤 휴대폰 뒤로가기를 눌러도 방금 나온 화면으로 다시 들어가지 않는다.
3. 아래 메뉴 "홈"이나 ← 로 홈에 오면 바로 다음 휴대폰 뒤로가기에 종료 안내(설치 앱).
4. 깊이 들어간 화면(하루 화면, 연동 기사 화면 등)은 지금처럼 한 장씩 돌아간다.
5. 저장 안 된 입력이 있으면 지금처럼 이동 전에 확인 창(`confirmLeaveIfUnsafe`).
6. 새로고침·알림·주소로 바로 들어온 경우(첫 기록이 홈이 아님)는 되감지 않고 교체 — 앱 밖으로 튕기지 않음.
7. 브라우저 탭(설치 안 한 상태)도 같은 규칙(기록이 덜 쌓일 뿐), 종료 안내는 지금처럼 설치 앱에서만.
