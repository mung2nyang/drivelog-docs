1. 지출이면 돌려주는 모양: `{ kind: 'expense', expense: { date, type, cost, name, category, fuelType, payment } }`.
   - `type`: `maint`(정비·수리·타이어·오일·부품) / `fuel`(주유·경유·기름·요소수) / `misc`(통행료·톨게이트·주차·과태료 등). 모르면 `maint`(앱 기본과 같음).
   - `date`: 운행과 같은 날짜 표에서 고름, 앞날이면 오늘(함수가 바꿈).
   - `cost`: 원 단위 0 이상 정수, 말 안 했으면 없음(null).

2. 운행·질문·관계없음은 지금과 똑같음(운행 칸·규칙 그대로).
3. 말하지 않은 칸은 null로 비움(24-A2와 같은 칸 모양 방식 — 지출 칸도 필수·null 허용).
