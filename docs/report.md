# docs/report.md — 현재 슬라이스 착수지시서

## 로드맵 80 기사 초대를 저장하면 그 차량의 기사 이름·전화번호도 바꾸기 `[x]`

71번 배포본 확인 중 발견, 로드맵 80번 등재 `[확인: 2026-10-14 보리 — 고칠 일로, sot에 정한 규칙 없음]`, 순서 ①. 77번 다음. 플레이북 트리거 해당(저장 경로) — `docs/testing-playbook.md` 열람함. DB 변경 없음.
`docs/sot.md` 확인: 기사 이름을 어디서 관리하는지 정한 규칙은 없습니다(`grep "driverName\|기사 이름" docs/sot.md` 0건). §8 "게스트 초대 UI 건드리지 마라"는 이번 범위(로그인 차주)와 무관합니다.
AGENTS §8-6: 원본 앱 대조 결과 **이관 누락**입니다. 원본은 초대를 서버에 저장한 뒤 그 차량의 기사 이름·전화번호를 초대 값으로 바꿨습니다(`ubiquitous-parakeet/driver-link.js:370-374` `assignedCar.driverName = nextLink.driverName; assignedCar.driverPhone = nextLink.phone`).

### 쉬운 요약
- **무엇을:** 로그인 차주가 기사 초대를 저장하면, 그 차량에 적힌 기사 이름·전화번호도 초대에 넣은 값으로 바꿔 서버에 저장합니다(원본과 같음).
- **왜:** 서버의 초대 기록에는 이름·전화번호 칸이 없어서, 앱을 다시 켜면 그 차량에 적힌 기사 정보로 보입니다. 그래서 초대 창에 "시험기사71"이라고 넣어도 다시 켜면 차량에 적힌 "66시험기사"로 바뀝니다.
- **달라지는 것:** 초대 창에 넣은 이름·전화번호가 다시 켜도 그대로 보입니다. 차량 관리 화면의 그 차량 기사 정보도 같은 값으로 바뀝니다.

### 현재 상태 (코드 확인)
- 불러올 때 `lib/hydrateMerge.js:82-83`이 초대의 이름·전화번호를 `car?.driverName || local.name`, `car?.driverPhone || local.phone`으로 채웁니다. 차량 값이 먼저입니다.
- 초대 저장 `lib/requestDriverInviteSave.js`는 서버 초대(`upsert_driver_link_idempotent`)만 저장하고 `commitDrivers`로 화면에 반영합니다(`:89-97`). 차량은 건드리지 않습니다.
- 차량 기사 정보가 서버에 담기는 곳(`lib/cloudStorage.js:67-86` `buildVehicleRow`): 이름은 `vehicles.driver_name` 칸과 `raw`, 전화번호는 `raw.driverPhone`(`hydrateMergeCars.js:61-62`)입니다.
- 차량 한 대만 서버에 고쳐 쓰는 기존 함수가 있습니다: `lib/syncVehiclesClients.js:38` `upsertVehicleFromList`. 같은 방식을 쓰는 곳은 `lib/vehicleMutations.js:118-153` `requestCarBusinessInfoSave`(기사 관리 사업자·계좌 저장)이고, 계정별 차례 지키기(`runOwnerSaveSerialized`)도 씁니다.
- 초대 저장을 부르는 곳은 두 곳입니다(71번 조사). 기사 연동 화면 `DriverConnectionPage.jsx:69`, 차량 등록과 함께 만드는 초대 `lib/carInviteFromDraft.js:75`. 후자는 차량 등록 창의 기사 이름·전화번호로 초대를 만들므로 이미 같은 값입니다.

### 목표 상태 (기대 동작)
1. 로그인 차주가 기사 초대를 저장하거나 고쳐서 서버 저장에 성공하면, 그 배정 차량의 기사 이름·전화번호를 초대 값으로 바꿔 서버 차량 기록에도 저장합니다.
2. 차량의 이름·전화번호가 이미 초대 값과 같으면 차량 저장 요청을 보내지 않습니다.
3. 다시 켜도 초대 목록과 차량 관리 화면에 초대에 넣은 이름·전화번호가 보입니다.
4. 초대 저장은 됐는데 차량 저장만 실패하면, 초대는 그대로 두고 "초대는 저장했지만 차량의 기사 이름·전화번호는 저장하지 못했습니다. 잠시 후 다시 저장해 주세요."를 띄웁니다. 차량 화면 값은 바뀌지 않습니다(서버 성공 뒤에만 반영, sot `:539`).
5. 초대 저장이 실패하면 지금처럼 안내만 하고 차량도 건드리지 않습니다.
6. 비회원은 그대로입니다(sot §8, 범위 밖).
