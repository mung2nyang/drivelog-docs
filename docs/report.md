### 쉬운 요약
- 지금은 앱을 쓰는 중에 인터넷이 끊겨도 아무 표시가 없다. 로그인 계정은 서버에 저장하는 방식이라(sot §9) 끊긴 동안 저장이 전부 실패하는데, 저장을 눌러 본 뒤 빨간 실패 알림을 보고서야 안다.
- 끊기면 화면 맨 위에 빨간 띠 "인터넷 연결이 끊겼습니다." / "다시 연결되기 전에는 저장되지 않습니다."를 띄우고, 다시 연결되면 띠가 사라진다.
- 화면 안내만이다. 저장 동작은 그대로이고 새 저장 장치는 없다(AGENTS §7).

### 현재 상태 (코드 확인)
- 쓰는 중 끊김을 알아채는 코드 없음: `navigator.onLine`·`offline` 이벤트 0곳(grep). "다시 연결됨"(`online`) 이벤트는 저장 다시 시도 2곳만 씀(`pendingWriteRetryListeners.js:57`, `syncFlushListeners.js:18`) — 화면 표시 없음.
- `public/offline.html`(18-E)은 인터넷 없이 앱을 **처음 열 때만** 나오는 안내 화면(`public/sw.js:1`).
- 로그인 계정은 서버가 정본이고 저장에 실패하면 다시 시도 없이 알림 후 멈춤(sot §9). 메인 차량 일지도 같음(`pendingWriteRetryListeners.js` 주석 "로그인 + 서버에 있는 메인 차량이면 그 일지는 Fail-Fast"). 비회원은 휴대폰에 저장해 인터넷과 무관.
- 화면 위 띠 선례: `HydrationRetryBanner.jsx`(서버에서 기록을 못 불러왔을 때 노란 띠, `AppShell.jsx:131`) — 색을 글자로 직접 적어 어두운 화면 대응이 없고, 아래로 내리면 위로 사라짐.
- 화면 맨 위 제목줄(`settings-header`)은 고정이 아니라 화면과 같이 움직임. 앱 화면 상자(`.main-app-container`) 위 여백 20px·좌우 16px(`app-shell-base.css:11-17`).
- sot에 끊김 안내 규칙 없음(grep "오프라인·끊김·onLine" — §6은 실패 문구만).

### 목표 상태 (기대 동작)
1. 로그인 계정이 앱 화면(로그인 뒤 모든 화면)을 쓰는 중 휴대폰이 "인터넷 연결 없음"으로 바뀌면 화면 맨 위에 빨간 띠: "인터넷 연결이 끊겼습니다." / "다시 연결되기 전에는 저장되지 않습니다." + 와이파이 끊김 그림, 화면 읽기 기능이 바로 읽어 줌(`role="alert"`).
2. 다시 연결되면 띠가 바로 사라진다. 따로 알림은 띄우지 않는다(그 순간 떠 있던 빨간 실패 알림을 덮지 않게 — 알림은 한 번에 하나).
3. 끊긴 채로 앱 화면에 들어와도 띠가 보인다.
4. 띠는 맨 위 제목줄을 가리지 않고 아래로 밀며, 아래로 내려도 맨 위에 붙어 있다. 옆 메뉴·창(팝업)·당겨서 새로고침 표시·아래 메뉴보다는 아래(앞을 가리지 않음).
5. 비회원(휴대폰 저장)에게는 띠를 보이지 않는다 — 끊겨도 저장되기 때문(보리 확인 2).
6. 저장·다시 시도·불러오기 동작은 그대로.
7. 한계(안 고침): 와이파이에는 붙어 있지만 인터넷이 안 되는 경우는 휴대폰이 "연결됨"으로 알려 띠가 안 뜬다(브라우저가 주는 연결 표시의 한계). 그때는 83번 빨간 실패 알림으로 알게 된다.
