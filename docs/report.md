## Capacitor 전환 C-3-B — 앱 안 카카오톡·문자 공유 `[x]`

2026-11-05 보리 요청("C-3-B 착수지시서 작성해"). 승인 `[확인: 2026-11-06 보리 — "착수지시서 확정, 작업 진행해"]`. 근거: 로드맵 "Capacitor 전환" C-3, 앞 조각 C-3-A(앱 안 파일 저장, react-app `fc3e936`)의 `saveFileToDevice`를 이어 씀. 이번엔 B(공유)만.

### 쉬운 요약
- 앱에서 운송비 내역서·일상점검표의 [공유] → 카카오톡으로 보내기를 누르면 지금은 "파일 공유를 할 수 없습니다" 알림만 뜹니다. 안드로이드 공유 창이 떠서 카카오톡을 고를 수 있게 합니다.
- 문자로 보내기는 앱에서 파일 저장이 조용히 실패하고 문자 앱만 열립니다. 파일을 문서/운행일지 폴더에 저장한 뒤 문자 앱을 열게 합니다.
- 웹 브라우저에서는 바뀌는 것이 없습니다.

### 현재 상태 (코드 확인)
- 공유는 공용 창 하나(`ShareFileModal.jsx`)를 운송비 내역서(`ReportShareModal.jsx`)와 일상점검표(`DailyInspectionShareModal.jsx`)가 같이 씀(`grep ShareFileModal` 결과 두 곳).
- 카카오톡: 브라우저 공유 기능(`navigator.share`)을 부름(`ShareFileModal.jsx:35-40`). 앱 안 화면(WebView)에는 이 기능이 없어 "파일 공유를 할 수 없습니다" 알림(에뮬레이터 확인, 2026-11-05).
- 문자: 링크로 파일을 내려받고 `sms:` 주소로 문자 앱을 엶(`ShareFileModal.jsx:57-68`). 앱에서는 링크 내려받기가 조용히 실패(C-3-A에서 확인한 것과 같은 원인). `sms:` 주소는 Capacitor가 휴대폰 문자 앱으로 넘김(`@capacitor/android` `Bridge.java` `launchIntent` — 앱 주소가 아닌 주소는 바깥 앱으로 엶).
- 공유용 파일 경로를 바깥 앱에 넘기는 설정(FileProvider, 캐시 폴더 포함)은 이미 있음(`AndroidManifest.xml` provider, `res/xml/file_paths.xml`의 `cache-path`).

### 목표 상태 (기대 동작)
1. 앱에서 카카오톡으로 보내기(PDF·이미지)를 누르면 안드로이드 공유 창이 뜨고, 고른 앱(카카오톡 등)에 파일과 안내 문구가 넘어간다. 공유 창 제목은 지금의 공유 제목("운송비 내역서", "일상점검표").
2. 공유 창을 그냥 닫으면(취소) 아무 알림도 없다(지금 웹과 같음). 다른 실패는 지금처럼 "카카오톡 파일 공유에 실패했습니다."
3. 앱에서 문자로 보내기를 누르면 파일을 `문서/운행일지/`에 저장한 뒤 문자 앱을 연다(받는 사람·문구는 지금처럼 채움). 저장 위치를 알림으로 보여 준다: "문자에 붙일 파일을 저장했습니다. 내 파일 > 문서 > 운행일지에서 볼 수 있어요."
4. 웹 브라우저에서는 카카오톡·문자 모두 지금과 같은 동작·같은 알림.
