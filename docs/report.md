- 앱 설정 "횟수 버튼 설정"에서 버튼을 길게 눌러 지우려 하면, 누르는 순간 숫자 칸이 잡혀 휴대폰 자판이 먼저 올라온다.

### 시안 (누를 때 흐름 — 화면 모양은 지금과 같음)
| 누르는 방법 | 지금 | 바꾼 뒤 |
|---|---|---|
| 짧게 톡 | 자판 뜨고 숫자 고침 | **같음**(떼는 순간 숫자 칸이 열리고 자판) |
| 길게 꾹(0.6초) | 자판이 먼저 뜨고 그 위로 삭제 창 | **자판 없이** 삭제 확인 창만 |
| 누른 채 밀기(스크롤) | 자판이 뜰 수 있음 | 아무 일 없음 |
| 숫자 고치고 다른 곳 누름 | 저장 | 같음(저장 뒤 다시 "보기만") |

### 목표 상태 (기대 동작)
1. 횟수 칩은 평소 "보기만"(읽기 전용) — 손가락이 닿아도 자판이 안 뜬다.
2. 짧게 누르고 떼면(길게 누르기 전, 밀지 않음) 그 칩이 고칠 수 있게 되고 바로 커서가 들어간다(자판).
3. 길게 누르면 지금처럼 삭제 확인 창, 자판은 안 뜬다. 버튼이 1개면 지금처럼 안 지워짐.
4. 칸을 벗어나면(blur) 지금처럼 저장되고 다시 "보기만".
5. 키보드(컴퓨터)로 칩에 와서 숫자를 누르면 고칠 수 있다.
