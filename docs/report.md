## 문의 답변 알림 "닫기"를 서버에 저장하기 `[x]` — 착수지시서 확정(2026-11-07 보리 "착수지시서 확정,작업진행해")

2026-11-07 보리 제보("답변 알림을 닫아도 앱을 다시 켜면 또 뜸", 기사 계정, 여러 번 발견) → 원인 조사(`docs/bugs.md`) → 보리 결정 "셋 다 고치자, 알람은 서버에 저장해". 확인할 점 1 "권함으로"(다른 알림은 따로), 2 "응 그렇게해"(나의 문의를 열면 봤음) — 착수지시서 확정 2026-11-07.
근거: sot §4 문의 알림 줄(`[확인: 2026-10-22 보리]` — 답변이 수정되면 다시 뜸).

### 쉬운 요약
- 지금은 [닫기]를 누른 기록이 그 휴대폰에만 남아, 다른 기기·연동 기사 계정에서는 다시 뜬다.
- 닫은 기록을 그 문의 줄에 서버로 저장해, 어느 기기·어떤 연동 상태에서든 한 번 닫으면 다시 안 뜨게 한다.
- 관리자가 답변을 고치면 다시 뜨는 규칙은 그대로 둔다.

### 현재 상태 (코드 확인)
- 알림 id `inquiryAnswer:<문의 id>:<답변 시각>`(`features/notifications/api/inquiryNoticeItems.ts:36`), 닫으면 기기 저장소 `reactPracticeDismissedNotifs:<ownerKey>`에만 저장(`features/notifications/api/notifications.js:38`).
- 연동 기사는 ownerKey가 차주 id라(`data/cloud/appSession.ts` `ownerKeyFromSession`) 연동·해제 때 닫은 목록이 바뀜 — 보리가 겪은 원인으로 봄.
- 웹에서 [닫기] → 새로고침은 다시 안 뜸(인앱 브라우저 "테스트2"로 확인) — 기기 안에서는 정상.
- 서버 `support_inquiries` 칸: id·user_id·type·title·content·status·answer·answered_at·raw·created_at, 정책은 본인 넣기·본인 읽기뿐(수정 정책 없음, 2026-11-07 조회). 답변은 관리자 함수가 `answered_at = now()`로 저장(`0025_support_admin.sql:97`).

### 목표 상태 (기대 동작)
1. 알림 화면에서 문의 답변 알림 [닫기] → 서버에 "이 답변을 봤음"이 저장되고 알림이 사라진다.
2. 같은 계정으로 다른 기기에서 켜도, 기사 연동·해제 뒤에도 그 알림은 다시 안 뜬다.
3. 관리자가 답변을 다시 저장하면(답변 시각이 바뀜) 다시 뜬다(지금 규칙 그대로).
4. 서버 저장이 실패하면 알림이 남고 "알림을 닫지 못했습니다. 잠시 뒤 다시 시도해 주세요." 안내.
5. 이미 이 기기에서 닫아 둔 알림은 계속 안 보인다(기기 목록 거르기 그대로 둠).
6. 남의 문의는 닫을 수 없다(서버 함수가 본인 문의만 바꿈).
7. 고객센터 "나의 문의"를 열면 거기 보인 답변은 모두 "봤음"으로 서버에 저장 → 알림 화면으로 가면 그 답변 알림이 없다.
   저장이 실패해도 나의 문의 화면은 그대로 보이고 안내도 띄우지 않는다(알림만 남음).
