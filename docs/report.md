## 11-A 계정 삭제 안내 페이지(구글 플레이 제출용) `[x]`

보리 요청(2026-11-03, "11번 착수지시서 써줘"). 근거: 로드맵 11번 "계정 삭제 안내 주소(앱 안 탈퇴는 이미 있음)". 10-P ⓓ 구글 브랜딩 끝난 다음 순서.

11번 전체를 나눈 순서(이번엔 **11-A만**):
- **11-A 계정 삭제 안내 페이지** — 플레이 콘솔이 요구하는 공개 주소. 코드는 이번 것만.
- 11-B 앱 연결 파일 `/.well-known/assetlinks.json` — 플레이 콘솔에서 앱을 만들어 서명 지문(SHA-256)을 받은 뒤. GitHub Pages가 점(.)으로 시작하는 폴더를 배포하는지 그때 확인.
- 11-C TWA 앱 파일(`.aab`) 만들기 — 패키지명 `com.getdrivelog.app`(보리 2026-10-08). 만드는 도구(PWABuilder 웹 / Bubblewrap)·서명 키 보관 위치는 그때 정함.
- 11-D 스토어 등록 자료 — 설명 문구·데이터 보안 항목·스크린샷·대표 이미지 1024×500 초안(AI 작성, 문서만), 심사용 테스트 계정.
- Play Console 개발자 등록: 보리가 2026-11-03 마침, 신원 확인(주소 서류) 심사 중. 게시만 막히고 11-A~C 준비는 그대로 진행.
- 비공개 테스트 테스터(최소 12명, 14일): 보리가 유료 모집 서비스로 20명 준비 `[확인: 2026-11-03 보리 — "오천원주면 해주는 플랫폼 할거니", "20명으로 한다하니까"]`.

### 쉬운 요약
- 구글 플레이에 앱을 올리려면 "앱을 안 깔고도 계정 삭제를 요청하는 방법"을 적은 공개 웹 페이지 주소가 필요하다.
- 처리방침·약관과 같은 모양으로 `getdrivelog.com/account-deletion.html` 한 장을 만든다.
- 하고 나면 플레이 콘솔 "계정 삭제" 칸에 이 주소를 넣을 수 있다. 앱 화면은 바뀌지 않는다.

### 현재 상태 (코드 확인)
- 앱 안 탈퇴는 있음: 마이페이지 → 개인정보 → 회원 탈퇴(처리방침 7항·이용약관 제16조), 서버 함수 `delete_own_account`(0009에서 연동 중이면 막음).
- 탈퇴 때 지워지는 것: 계정·개인정보·사업자 정보·본인 차량 기록, 고객센터 문의(0025 `on delete cascade`), 앱 오류 기록(0021 `on delete cascade`). 남는 것: 소속 기사가 차주 차량에 쓴 기록은 작성자만 비우고 차주 장부에 남음(0008 `on delete set null`).
- 앱 밖에서 삭제를 요청하는 안내 페이지는 없음(`react-app/public`에 privacy·terms·offline만).

### 목표 상태 (기대 동작)
1. `https://getdrivelog.com/account-deletion.html`이 열리고, 처리방침·약관과 같은 모양(밝은/어두운 테마, 휴대폰 폭)이다.
2. 앱 안에서 삭제하는 방법(마이페이지 → 개인정보 → 회원 탈퇴, `PersonalInfoPage.jsx` 170줄 단추)과 연동 중이면 먼저 해제해야 한다는 점, 탈퇴 전 기록 내려받기 권장(처리방침 7항과 같은 내용)이 있다.
3. 앱을 쓸 수 없을 때 요청하는 방법: 가입한 구글 계정 이메일로 ya01na111@gmail.com에 요청 → 본인 확인 뒤 지체 없이 삭제.
4. 지워지는 정보와 남는 정보(위 "현재 상태"와 같게), 서버에 따로 보관하는 기간 없음이 적혀 있다.
5. 비회원은 서버에 저장된 정보가 없고 브라우저 데이터 삭제로 지운다는 안내가 있다.
6. 처리방침·이용약관 링크가 아래에 있다. 앱 코드·화면은 그대로다.
