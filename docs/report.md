### 목표 상태 (기대 동작)
1. **카드 열고 닫기**: 운비서 줄을 누르면 같은 카드가 아래로 늘어나 입력 부분이 나옴, 다시 누르거나 [닫기]면 접힘. 안내 문구는 확인할 점 2.
2. **비회원**: 늘어난 카드에 "로그인하면 쓸 수 있습니다."만, 서버를 안 부름.
3. **말하기**: 받아쓰기를 지원하는 브라우저에서만 마이크 버튼. 누르면 "듣는 중…" → 끝나면 받아쓴 글자를 글 칸에 넣고 확인할 점 1대로 보냄. 다시 누르면 듣기 멈춤. 마이크 권한을 거절하면 "마이크 권한을 켜 주세요. 글로 써도 됩니다." 지원 안 하면 마이크 버튼 없이 글 칸만.
4. **쳐서 넣기**: 글 칸(300자까지) + [보내기](엔터도). 빈 칸이면 못 보냄.
5. **보내기**: 서버에 `text`·오늘 날짜(이 휴대폰 날짜)·`clientNames`(내 거래처 이름, 200개까지)를 한 번. 기다리는 동안 "알아듣는 중…"이고 다시 보내기·마이크 잠김. 한 번에 하나, 재시도 없음.
6. **결과 글**(앱이 정해진 틀로 만듦 — AI 문장 아님), 맨 위에 **"내가 한 말: …"**:
   - 운행: "{날짜} {상차지} → {하차지}, {운송료}원, {거래처}(으)로 알아들었어요." — 날짜는 오늘이면 "오늘", 아니면 "10월 21일"; 빈 칸은 빼고(예: 금액 없으면 금액 부분 없음). 다음 B-2에서 이 아래에 [입력 창 열기].
   - 지출: "지출 기록은 곧 할 수 있게 됩니다." / 질문: "질문 답하기는 곧 할 수 있게 됩니다." / 관계없음: "운행 기록으로 알아듣지 못했어요. 다시 말해 주세요."
   - 실패: 401 "로그인이 필요합니다." / 400 "말이 너무 길거나 비었어요. 300자까지 다시 말해 주세요." / 502 "알아듣지 못했습니다. 다시 말해 주세요." / 503·연결 끊김·그 밖 "잠시 뒤 다시 시도해 주세요."
7. 서버 응답은 칸마다 모양을 확인해 좁힘(AGENTS §6, 모르는 `kind`·모양이 틀리면 "알아듣지 못했습니다"). 저장·일지 변경 없음.
8. 홈의 다른 카드(오늘·할 일·이번 달)는 그대로.
