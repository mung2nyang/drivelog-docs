### 목표 상태 (기대 동작)
1. 질문이면: `{ kind: 'question', question: { type, period, client, expenseType } }`.
   - `type`: `revenue`·`netProfit`·`expense`·`unpaid`·`trips`·`other`.
   - `period`: `{ unit: 'month', value: 'YYYY-MM' }` / `{ unit: 'year', value: 'YYYY' }` / `{ unit: 'all' }`(미수금 기본) / `{ unit: 'unsupported' }`. AI는 함수가 만든 **달 표**(이번 달·지난달·올해·작년 + 올해 1~12월)에서 고르기만. 앞날 달(예: 10월에 "12월")은 작년 그 달, 앞날 연은 올해(함수가 바꿈). 말이 없으면 이번 달(미수금은 all).
   - `client`: 거래처 목록과 맞으면 그 이름, 아니면 들은 그대로, 없으면 빈 칸(운행과 같은 규칙).
   - `expenseType`: `expense`일 때만 `maint`·`fuel`·`misc`, 말 안 했으면 빈 칸(전체).
2. 운행·지출·관계없음은 지금과 똑같음.
3. 말 안 한 칸은 null로 비움(지금 칸 모양 방식).
4. 기록·로그인 확인·입력 검사·실패 문구 그대로. 계산·저장 안 함.
