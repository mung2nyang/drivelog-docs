### 쉬운 요약
- 앱에서 휴대폰 뒤로가기를 누르면 어느 화면이든 바로 앱이 닫힙니다. 크롬이나 예전 플레이 앱(1.0.1)처럼 앞 화면으로 돌아가게 합니다.

### 현재 상태 (코드 확인)
- Capacitor 기본 틀(`@capacitor/android` 8.6.0)에는 뒤로가기 처리가 없음(`BackPressed`·`goBack` 검색 0건) → 안드로이드 기본 동작대로 화면(액티비티)을 닫음.
- 2026-11-06 에뮬레이터(디버그 앱): 앞 화면 기록을 하나 더 쌓은 상태(`history.length` 2)에서 뒤로가기 → 앱이 닫히고 바탕화면이 맨 위로.
