1. 앱 안에서 로그인 버튼을 누르면 안드로이드 구글 계정 선택 창이 뜨고, 고르면 로그인되어 홈으로 간다. 그 뒤 처리(첫 로그인 프로필 만들기 등)는 지금과 같은 부트 복원이 맡는다.
2. 계정 선택을 취소하거나 실패하면 토스트 "구글 로그인을 마치지 못했습니다. 다시 시도해 주세요."가 뜨고 버튼을 다시 누를 수 있다.
3. 웹 브라우저에서는 지금처럼 `signInWithOAuth`로 구글 화면에 다녀온다(바뀌는 것 없음).
