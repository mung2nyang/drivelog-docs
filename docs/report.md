보리 요청(2026-11-03, "응 작성해"). 근거: 로드맵 11번 "TWA: Bubblewrap/PWABuilder로 `.aab` 생성, 서명 키 보관", 11-A(`465e3a1`) 다음. 11-B(assetlinks)는 이 슬라이스에서 나오는 서명 지문이 있어야 해서 순서를 바꿔 11-C를 먼저 한다. 이번엔 **11-C만**.

### 쉬운 요약
- getdrivelog.com을 감싼 안드로이드 앱 파일(.aab, 플레이 제출용)과 휴대폰 시험용 파일(.apk), 서명 키를 만든다.
- 앱 코드는 바꾸지 않는다. 화면·기능은 지금처럼 웹 배포로 고치고, 앱 파일은 아이콘·이름·휴대폰 권한을 바꿀 때만 다시 만든다.
- 끝나면 휴대폰에 시험용 앱을 깔아 열 수 있다. 위쪽 주소창은 11-B(assetlinks)가 끝나야 사라진다.
