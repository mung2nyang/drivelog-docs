## 11-D-2 스토어 그림 자료(대표 이미지·스크린샷) `[x]`

보리 요청(2026-11-03, "시작하자"). 근거: 로드맵 11번 "스토어 이미지(아이콘 512px·대표 이미지 1024×500·폰 스크린샷 2장 이상)", 11-D-1(`d719b80`) 다음. 이번엔 **11-D-2만**(11-D-3 심사용 접근은 다음).

### 쉬운 요약
- 플레이 스토어 앱 화면에 걸릴 그림을 만든다: 맨 위 대표 이미지 1장, 휴대폰 화면 사진 5장.
- 화면 사진은 비회원 모드에 지어낸 예시 기록을 넣어 찍는다 — 실제 사용자 정보가 안 나오고, 예시 기록은 서버로 안 간다.
- 대표 이미지는 시안을 먼저 보여 드리고 확인 뒤 확정한다. 앱 코드는 안 바뀐다.

### 현재 상태 (코드 확인)
- 앱 아이콘 512: `react-app/public/icons/icon-512.png` 512×512, 32비트 PNG, 201KB — 플레이 조건(512×512, 1MB 이하) 충족, 새로 안 만듦.
- 대표 이미지·스크린샷 없음. 쓸 수 있는 그림: `public/images/banner_image*.png`(로그인 화면 그림), 운비서 캐릭터 `assistant_unbiseo.png`, 트럭 로고.
- 비회원은 기록을 브라우저에만 저장(처리방침 2항 끝, `App.guestDurable.test.js`) → 촬영용 별도 브라우저 프로필에 예시 기록을 넣어도 서버·실사용자와 섞이지 않는다.
- 촬영 도구: 이 PC에 Edge·Chrome 설치됨, Node 24. 화면 자동 조작 라이브러리(Playwright 등)는 react-app에 없음 → 새로 설치하지 않고 Edge를 원격 조작 모드로 띄워 Node 기본 기능으로 조작·촬영.
- drivelog-docs 저장소는 공개(PUBLIC) — 넣을 그림은 어차피 스토어에 공개될 예시 화면뿐이라 문제없음.
