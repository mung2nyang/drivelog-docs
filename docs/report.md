## 설정 "운비서" 하나로 홈 카드까지 끄기 `[x]`

보리 요청(2026-11-07): 앱 설정의 "운비서 버튼" 이름을 "운비서"로 바꾸고, 끄면 홈 화면의 운비서 카드까지 전부 꺼지게. 앞 작업 "운비서 버튼 설정"(drivelog-docs `d65beaf`)을 넓히는 것.

### 쉬운 요약
- 설정의 스위치 이름을 "운비서"로 바꾼다.
- 이 스위치를 끄면 다른 화면의 떠 있는 운비서 버튼뿐 아니라 홈 화면의 "AI 운비서" 카드도 사라진다. 다시 켜면 둘 다 돌아온다.
- 예전에 꺼 둔 사람은 그대로 꺼진 상태로 이어진다(저장 이름을 그대로 쓰므로).

### 현재 상태 (코드 확인)
- 설정 스위치 글자는 "운비서 버튼", 로그인 계정의 메인 설정에만 보인다 — `AppSettingsPage.jsx:99-107`(`!logId && ownerKey !== 'guest'`).
- 떠 있는 버튼은 끄면 이미 사라지고, 열린 카드를 접고 듣기도 멈춘다 — `UnbiseoDock.tsx:17-24`.
- 홈 카드(`HomeAssistantBar.jsx`, `HomePage.jsx:77`)는 이 설정을 보지 않아 꺼도 그대로 보인다.
- 저장 칸 설명이 "홈이 아닌 화면의 운비서 버튼"으로 되어 있다 — `financeTypes.ts:89`.

### 목표 상태 (기대 동작)
1. 앱 설정 스위치 글자가 "운비서"다(스위치 자리·처음 켜짐·저장 이름 `unbiseoDockOn`은 그대로).
2. 로그인 계정에서 끄면 홈 화면의 "AI 운비서" 카드가 보이지 않는다. 홈의 나머지 카드(오늘·할 일·이번 달) 순서는 그대로다.
3. 카드가 듣는 중에 꺼지면 듣기를 멈춘다(떠 있는 버튼과 같은 처리).
4. 다시 켜면 홈 카드가 접힌 상태로 다시 보인다.
5. 떠 있는 버튼의 동작은 지금과 같다.
6. 비회원(guest)은 스위치가 없으므로 홈 카드가 지금처럼 보이고 "로그인하면 쓸 수 있습니다." 안내가 그대로다.
